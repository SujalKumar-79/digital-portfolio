# Digital Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript to showcase projects, technical skills, certifications, and professional information through a clean, responsive interface.

## Overview

This repository contains the source code for my digital portfolio website. It provides a central place to explore my work, view project details, access certificates, and download my résumé.

## Features

- Responsive website layout
- Personal introduction and profile section
- Projects showcase
- Technical skills section
- Certifications and achievements
- Education timeline
- Contact and social media links
- Résumé download
- Interactive navigation and theme toggle

## Getting Started

No installation, package manager, or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/SujalKumar-79/digital-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd digital-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for local development.

## Customization

- Update website content in `index.html`.
- Modify styling and responsive layouts in `style.css`.
- Update interactive behavior in `script.js`.
- Add or replace images, certificates, and other resources in the `assets/` directory.
